# Topic 36 Web Demo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bổ sung dashboard React/Vite và FastAPI API sử dụng trực tiếp Python OOP core, sẵn sàng build trên Vercel nhưng chưa deploy.

**Architecture:** FastAPI adapter tạo session mô phỏng hoàn toàn trong bộ nhớ và trả timeline, snapshots, alerts, errors, summary cùng nội dung export. React gọi `/api/simulate`, hiển thị dashboard responsive và tạo file tải xuống từ đúng response hiện tại. FastAPI phục vụ `dist/` sau các API routes để frontend/backend dùng cùng domain.

**Tech Stack:** Python 3.13 local / Python 3.12+ Vercel, FastAPI 0.117.1, React 19, Vite, Vitest, Testing Library.

**Spec:** MASTER HANDOFF V1.0, `docs/governance/G0_DECISION_LOG.md`, yêu cầu Full Web Demo.

## Global Constraints

- Không phá API hoặc test CLI hiện có.
- Không database, authentication hay persistent filesystem.
- API deterministic theo MSSV và steps; steps giới hạn 1–200 cho serverless.
- Comment/docstring Python/JS bằng tiếng Việt không dấu; identifiers bằng tiếng Anh.
- UI, README và tài liệu bằng tiếng Việt có dấu.
- Không deploy production trong task này.

## Review Focus

- Response API phải dùng core thật và không tạo dữ liệu giả.
- Environmental alerts phải tách khỏi device/data errors.
- Download CSV/JSON phải khớp session đang hiển thị.
- Empty/loading/error/reset và accessibility phải hoạt động.
- CLI 64 test cũ phải tiếp tục PASS.
