# Topic 36 MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Xây dựng MVP Python OOP mô phỏng giám sát nhiệt độ và độ ẩm kho, có cảnh báo, thống kê, console, export và kiểm thử end-to-end.

**Architecture:** `main.py` điều phối Simulation → Sensor/Manager → Alert → Statistics → Display. Năm module có owner riêng, giao tiếp duy nhất qua schema trong MASTER HANDOFF V1.0 và G0.

**Tech Stack:** Python 3.11+, standard library, `unittest`, CSV, JSON.

**Spec:** `docs/governance/G0_DECISION_LOG.md` và MASTER HANDOFF V1.0.

## Global Constraints

- Không đổi API/schema đã khóa.
- Comment/docstring/TODO/FIXME bằng tiếng Việt không dấu; identifier bằng tiếng Anh.
- README và báo cáo bằng tiếng Việt có dấu.
- Mỗi worker chỉ sửa owned files.
- Không dependency ngoài Python standard library.
- Không merge vào `main`.

## Review Focus

- Sensor không ACTIVE phải giữ reading cũ và trả `False`.
- Giá trị `bool`, NaN, infinity và timestamp không timezone phải bị từ chối.
- Biên exclusive bằng ngưỡng phải là WARNING, không phải NORMAL.
- Snapshot cũ không được sinh lại alert hoặc tăng statistics.
- Duplicate `(sensor_id, timestamp)` không được ghi hai lần.
